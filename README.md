# AEROX — 3D Paper Airplane Flight Simulator

AEROX is a serene 3D paper airplane flight simulation web game. Players launch, fly, and drift paper airplanes in an interactive, living 3D environment.

![AEROX Hero Banner](aerox-hero-banner.jpg)

## 🌟 Key Features

- ✈️ **Serene Aero Physics**: Smooth pitching, banking, roll mechanics, and 360° barrel rolls.
- 🌱 **Persistent Sunflower Crash Garden**: Paper airplanes carry seeds—whenever you crash, a sunflower sprouts and remembers your flight coordinates in the global garden.
- ⛵ **Paper-to-Boat Morphing**: Gliding low over ponds automatically transforms your paper plane into a floating paper boat.
- 🌬️ **Dynamic Shifting Winds**: Mid-flight wind shifts require steering with wind vectors to gain speed boosts.
- 🎨 **Unlockable Skins**: Reach 1,000m and 5,000m milestones to unlock Sunset and Aurora paper plane skins.
- 🚀 **Zero Signups & Instant Launch**: Play directly from the landing page with WebGL acceleration.

## 🕹️ Controls

| Action | Control Key |
| :--- | :--- |
| **Pitch Down / Dive** | `W` or `Up Arrow` |
| **Pitch Up / Climb** | `S` or `Down Arrow` |
| **Bank Left** | `A` or `Left Arrow` |
| **Bank Right** | `D` or `Right Arrow` |
| **360° Barrel Roll** | `G` |

## 🛠 Tech Stack

- **Frontend**: HTML5, Vanilla CSS, JavaScript, Three.js (WebGL)
- **Backend / DB**: Netlify Serverless Functions, Drizzle ORM, PostgreSQL
- **Typography & UI**: Google Fonts (`Outfit`, `Inter`, `Playfair Display`), Glassmorphic Design System
